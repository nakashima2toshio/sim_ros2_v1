## 手順書の書き方

各手順書は次の構成をとる。

| 章 | 内容 |
|---|---|
| 冒頭の表 | ステージ・難易度・目安時間・対応する公式チュートリアル |
| 0. 準備 | 使う画面とターミナルの役割 |
| Step 1〜 | **実行するコマンド**と、その直後の**期待される結果**（ターミナルの表示・ブラウザの見え方） |
| 到達確認 | 答えられたら完了とする問い |
| うまくいかないとき | 症状 → 原因 → 対処の表 |
| 到達確認の答え | 最後に置く（先に見えないように） |

**期待される結果に書く値（ノード名・ログの文言など）は、推測で書かない。**
実機で確かめたか、ソースで確かめたものだけを書き、どちらで確かめたかを変更履歴に残す。
